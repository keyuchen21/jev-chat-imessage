# Privacy and data flow

The core rule is **read-only**: no injection, no hooks, no reading the Messages database
(`chat.db`), no automatic sending. This page says **what leaves your Mac and where it goes**.

## What stays on your Mac

- **Reading Messages**: the app reads text from the macOS accessibility tree of the open
  Messages window. In memory only. No screenshots, no OCR, no database access.
- **Logs** (`~/Library/Logs/jev-imessage.log`): stage timings only. No message text, no
  background notes, no candidate replies, no error bodies from model services.
- **Local judgment** (optional, `decider-2b`, about 3.8 GB): fully offline after download.
- **Keys**: `~/.config/jev-imessage/env` (mode 600). Never uploaded.

## Local conversation data

History is **off by default**. When on, each chat keeps at most the 100 most recent messages
the app actually saw (yours and others'). It never imports full chat history.
History and background notes are stored in plain text at
`~/Library/Application Support/jev-imessage/conversations.json` (mode 600), keyed by chat
title. Uninstalling the app does not delete this file.

## What is sent, and to whom

When a new message arrives, the app sends the message, the selected context (history and
your background notes, if enabled) to the services **you configure**:

- **Judgment** (TypeSafe Jev, directly or through a gateway such as OpenRouter): message and
  context; for ranking, also the candidate replies.
- **Generation** (any OpenAI- or Anthropic-compatible endpoint): message and context.

Options, most private first:

1. **Local only**: local judge model + a local generation server (for example Ollama at
   `http://localhost:11434/v1`). Nothing leaves your Mac.
2. **Your own keys** (recommended): text goes straight from your Mac to the providers you
   chose. It does not pass through any server run by this project.
3. **Built-in shared channel** (used only when no generation key is set): inherited from
   jev-chat-jarvis-mac. Text goes through a relay run by the original author to an upstream
   model provider, **over plain HTTP**. Do not use it for anything private; set your own key.

The app has no telemetry, no cloud sync and no backend storage. Providers and relays follow
their own retention policies.

## Disclaimer

Candidate replies are generated by models and are suggestions only. You decide what to send,
and you press Return yourself.
